This repository is the supplementary material for the paper “Laws of Production and Laws of Econometrics: The Humbug Identification of the Marginal Productivity of Capital.” It contains the simulation code and the complete simulation outputs summarized in the paper. The code runs in an Anaconda Python environment with Jupyter Notebook/JupyterLab. The code was prepared with assistance from AI-based coding tools, specifically Zcode’s GLM-5.3 and DeepSeek V4.1 Flash. All code and outputs were reviewed, tested, and validated by the authors, who take full responsibility for them.
